# Spider Panel — Telegram Admin Bot (Expanded)

ربات تلگرام خصوصی (فقط برای ادمین) که به API پنل [spider--panel](https://github.com/xxkhosma15/spider--panel) وصل می‌شه و تقریباً تمام کارهای مهم پنل رو از تلگرام انجام می‌ده.

## امکانات

### 👥 کاربران
- لیست کاربران (صفحه‌بندی)
- ساخت کاربر جدید (انتخاب اینباند، سقف ترافیک، مدت اعتبار)
- مشاهده جزئیات + وضعیت فعال/غیرفعال
- گرفتن تمام کانفیگ‌ها (متن) + لینک صفحه ساب
- گرفتن QR کد
- فعال / غیرفعال کردن کاربر
- ریست ترافیک
- حذف کاربر

### 📥 اینباندها
- لیست اینباندها
- ساخت سریع اینباند (VLESS+WS+TLS / Reality / Worker)
- تولید کلیدهای Reality جدید
- تولید Short ID جدید
- حذف اینباند

### 📊 آمار سرور
- CPU / RAM / Disk / Uptime / Connections

### ☁️ Cloudflare Worker
- وضعیت اتصال
- Sync کاربران به Worker
- Sync Source پروکسی‌ها
- مشاهده لوکیشن‌ها

### 🔍 اسکنر IP
- مشاهده لیست IPهای ذخیره‌شده Cloudflare و Railway  
  (اسکن واقعی همچنان از مرورگر پنل انجام می‌شود)

### 📁 گروه‌ها
- لیست گروه‌ها
- ساخت گروه
- حذف گروه

### ⚙️ تنظیمات
- تغییر پسورد پنل از داخل ربات

## نصب و اجرا

```bash
pip install -r requirements.txt
cp .env.example .env
# مقادیر داخل .env رو پر کن
python bot.py
```

## متغیرهای محیطی (.env)

| متغیر | توضیح |
| --- | --- |
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_CHAT_ID` | آیدی عددی تلگرام خودت (از [@userinfobot](https://t.me/userinfobot)) — ربات فقط به این آیدی جواب می‌ده |
| `PANEL_URL` | آدرس پنل روی Railway (بدون `/` آخر) |
| `PANEL_ADMIN_PASSWORD` | پسورد داشبورد وب پنل |

## دیپلوی روی Railway (اختیاری)

1. این پوشه رو توی یه ریپوی گیت‌هاب push کن.
2. توی Railway: **New Project → Deploy from GitHub**.
3. متغیرهای بالا رو توی Variables ست کن.
4. چون ربات polling است، نیازی به دامین/پورت نیست.

## نکات

- بعضی کارهای خیلی پیچیده پنل (مثل اسکن IP واقعی از مرورگر، تنظیم کامل Worker با توکن Cloudflare، ویرایش پیشرفته اینباند با همه فیلدها) هنوز راحت‌تر از داشبورد وب انجام می‌شوند. ربات تمرکزش روی کارهای روزمره ادمین است.
- اگر فیلدهای `POST /api/users` در فورک پنل شما فرق داشت، فقط تابع `create_user_confirmed` در `bot.py` را هماهنگ کنید.
- ربات فقط به `ADMIN_CHAT_ID` جواب می‌دهد.

## امنیت

- هیچ توکن یا پسوردی داخل کد نیست — همه از `.env` خوانده می‌شود.
- `.env` را هرگز push نکنید.
